# Курсовой проект по фреймворкам Python для анализа данных

Сравниваем влияние ручного и искусственного обогащения данных на качество и устойчивость моделей машинного обучения. Используем отзывы на русском языке и изображения для детекции людей и касок.

Сейчас готовим EDA исходных данных, рабочие выборки и codebook. Основной код находится в ноутбуках. Codebook и журнал ведём в Google Документах; ссылки добавим после создания документов.

## Данные

| Набор | Источник | Задача | Лицензия источника |
| --- | --- | --- | --- |
| Отзывы | [ai-forever/ru-reviews-classification](https://huggingface.co/datasets/ai-forever/ru-reviews-classification) | Классификация тональности: negative, neutral, positive | Apache-2.0 |
| Изображения | [BAC_HIEN_CONSTRUCTION_SAFETY_2024, v8](https://universe.roboflow.com/constructionsatefy/bac_hien_construction_safety_2024/dataset/8) | Детекция Helmet, Person, No-Helmet | CC BY 4.0 |

Текстовые данные загружены полностью: 45 000 записей в train, по 15 000 в validation и test. Версия, адреса файлов и контрольные суммы сохранены в `data/raw/reviews/source.json`.

Изображения v8 загружены в формате COCO JSON в `data/raw/safety/`: 15 566 в train, по 1 945 в valid и test. Всего 19 456 изображений и 58 376 объектов. В исходных документах экспорта указано отсутствие аугментаций. Сведения об источнике и контрольные суммы файлов разметки сохранены в `data/raw/safety/source.json`.

Базовая проверка не выявила пропущенных файлов, неверных ссылок на изображения и классы. Все 15 выборочно открытых изображений читаются, их размеры совпадают с разметкой. При проверке геометрии обнаружены 514 рамок, выходящих за границы изображения не более чем на 1 пиксель, и одна рамка с нулевым размером. Это особенности исходных аннотаций, которые нужно учесть при подготовке данных. Результаты сохранены в `reports/safety/basic_check.json`; исходные файлы разметки не изменялись.

Рабочие ориентиры: 3 000 отзывов и 4 000 изображений суммарно по всем выборкам. Правила отбора и итоговый состав зафиксируем после EDA. До этого сохраняем исходные данные целиком.

`raw` содержит исходные файлы, `processed` предназначен для подготовленных выборок. В `manifests` сохраняем списки выбранных ID, файлов и их принадлежность к выборкам. Таблицы и графики текстового EDA выводятся в ноутбуке. В `reports/safety` пока находится результат базовой проверки изображений.

Исходные и обработанные массивы данных исключены из Git. Код, конфигурация, сведения об источниках, списки выбранных объектов и результаты EDA сохраняются в репозитории.

## Окружение и запуск

Зависимости и их версии заданы в `pyproject.toml`. Требуется Python 3.12 или новее; текущее локальное окружение `.venv` использует Python 3.14.4. Установка проекта с зависимостями и запуск JupyterLab из корня проекта:

```bash
.venv/bin/python -m pip install -e .
.venv/bin/python -m jupyter lab
```

Откройте нужный ноутбук и выберите ядро из `.venv`. В `01_reviews_eda.ipynb` выполнены все 12 кодовых ячеек: проверка источника, знакомство с отзывами, фильтр алфавита, удаление дублей и конфликтных групп, отбор рабочего набора, проверка и сохранение результата. Размер, классы, доли разбиений, число примеров для просмотра и seed заданы в `config.yaml`.

После очистки осталось 61 785 отзывов. Рабочий набор из 3 000 записей сохранён в `data/processed/reviews/`: по 1 000 на класс, с сохранением исходных разбиений и долей 60/20/20. В train 1 800 записей, в validation и test по 600. Повторов по `strip().lower()` и пересечений между разбиениями нет. Все метки вручную пока не проверены.

Список выбранных ID находится в `data/manifests/reviews/selected_reviews.csv`. Проверки, сводные таблицы и графики доступны в выводах ноутбука. Выгруженные файлы проверены: все 10 проверок пройдены, выбранные ID совпадают с предыдущим запуском, исходные тексты и метки сохранены. Для полного повторения перезапустите ядро и выполните все ячейки ноутбука. Ноутбук изображений пока содержит только вводную часть и определение путей.

## Скачивание изображений

Войдите в Roboflow и получите Private API Key в настройках аккаунта или workspace. После установки зависимостей выполните из корня проекта:

```bash
.venv/bin/python - <<'PY'
from getpass import getpass
from pathlib import Path

import yaml
from roboflow import Roboflow

config = yaml.safe_load(Path("config.yaml").read_text(encoding="utf-8"))
settings = config["datasets"]["safety"]
client = Roboflow(api_key=getpass("Roboflow API key: ").strip())
version = client.workspace(settings["workspace"]).project(settings["project"]).version(settings["version"])
dataset = version.download(settings["format"], location=settings["raw_dir"], overwrite=True)
print(dataset.location)
PY
```

Ключ вводится в терминале без отображения символов и используется только для текущего скачивания. Ожидаемая структура выгрузки: папки `train`, `valid`, `test` с изображениями и файлами `_annotations.coco.json`.
